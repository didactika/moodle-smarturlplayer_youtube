# Smart URL · YouTube player

Configure the provider to show captions, enable inline playback, and control the visibility of YouTube player controls. Smart URL still provides standard YouTube previews when this extension is absent.

Install this directory at `mod/smarturl/media/player/youtube` in Moodle 4.5 or `public/mod/smarturl/media/player/youtube` in Moodle 5.3. Use the release that matches the Moodle version, and install Smart URL first.
